# 🛍️ JC_ATELIER — Modern E-Commerce Frontend

JC_ATELIER is a clean, responsive **static e-commerce frontend template** built using **pure HTML and CSS**.  
It includes essential storefront pages such as product listing, product details, cart, account, about, and contact pages — ideal for quick prototyping or showcasing UI/UX skills in a portfolio.

🔗 **Live Demo:** https://brainwave-matrix-intern-t2-e-commer.vercel.app/

## 🛠️ Technologies Used

- **HTML5** — Semantic structure for all pages  
- **CSS3** — Styling and responsive layout design  
- **Google Fonts** — Poppins typeface  
- **Font Awesome** — Icon set via CDN  
- **Boxicons** — Icon pack via CDN 

---

## ⭐ Features

- ✔️ Multi-page storefront (Home, Products, Product Details)  
- ✔️ Fully responsive layout (mobile-friendly)  
- ✔️ Product detail gallery with thumbnail switching  
- ✔️ Shopping cart layout with price summary and quantity input  
- ✔️ Login/Register toggle UI on Account page  
- ✔️ Contact form and About page with social links  
- ✔️ Reusable footer with app store badges and icons
